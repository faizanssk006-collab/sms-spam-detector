ℹ️ About Model Architecture & Dataset ▼

This project uses Natural Language Processing (NLP) techniques trained on the SMS Spam Collection dataset (5,572 messages):

  • Preprocessing: Text lowercase normalization, URL removal, punctuation stripping, and tokenization.
  • Feature Extraction: TfidfVectorizer with English stop words filter and 3,000 max features.
  • Classifier: MultinomialNB (Multinomial Naive Bayes) achieving 97.39% accuracy and 100.0% precision.
  • Zero Backend Delay: Mathematically identical to Scikit-learn, executing in your browser via client-side vector weights.
